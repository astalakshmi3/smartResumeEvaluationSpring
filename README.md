# Smart Resume Evaluation

## A Spring Boot + Spring AI project that compares a candidate’s resume with a job description and returns structured AI-powered feedback.

This project uses OpenAI through Spring AI to analyze:

* Resume strengths
* Missing skills
* Match score
* Improvement suggestions
* Overall summary

## Technologies Used
*  Java 25
*  Spring Boot 4
*  Spring AI
*  OpenAI API
*  Maven
*  REST API
*  Swagger / OpenAPI
*  Postman

## Features
* Compare resume with job description
* AI-powered candidate analysis
* Structured JSON response
* Match score generation
* Missing skills detection
* Personalized feedback
* Clean layered architecture
* Uses SystemMessage and UserMessage
